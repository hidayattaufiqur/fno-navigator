fno-navigator — UI strip-down: before / after

Audit + redesign proposal (task t_ff324619). Full spec in DESIGN.md; wireframes in redesign-wireframes.excalidraw; audit in AUDIT.md.

1 · Table detail — the 9-element title stack vs one title block
Before 9 elements before data
  • Full-width module badge band competes with trace buttons (both green for Inventory)
  • 34px mono heading + breadcrumb + sidebar = "InventTable" 3× before data
  • Trace buttons styled differently for sibling actions
  • ~40 colored elements on one page; 25+ of them the same teal accent
  • TOC pills 23px, section toggles 18px, pager buttons 24px — all under target
After one title block, one accent
[INVENTORY] chip + docs link
InventTable (28px, largest text on page)
description (muted, 14px)
[⇢ Trace from] [⇠ Trace to] — same secondary style
  • Module chip replaces the full-width band; module color = data color only
  • Accent means interaction — links, active state, primary button; never headings
  • Both trace buttons share one secondary style
  • Hit targets ≥ 44px mobile / ≥ 32px desktop
  • Data-first: table names & FK fields are the most legible text
2 · /find results — badge overload vs one badge max
Before 50 rows × badges
  • 47 of 50 rows carry "shortest" — a property of the sort mode, not the row
  • Row #1 doubles up shortest + cleanest; "cleanest" never explained
  • Table names colored blue = source / green = target, but the same blue paints the button, sidebar, badges — color cannot be read as a system
  • Breakdown duplicates headline: 2 hops · score 10 · via X (hops implied by arrows, X in headline)
  • "click a table name" instruction buried in a muted meta line
After one badge max
#1 InventTable → IntrastatStatProc → SalesTable cleanest
IntrastatStatProc.StatProcId → InventTable.IntrastatProcId_CZ
SalesTable.StatProcId → IntrastatStatProc.StatProcId
  • "shortest" badge removed — the header states "shortest first"
  • Rank #1 highlighted with accent border + single "cleanest" badge
  • Neutral table names, bold source/target, accent on hover
  • FK field labels stay — they are the real value
  • Badge legend moves next to the results ("What do badges mean?")
3 · Graph toolbar — 10 floating pills vs one select
Before glass toolbar, orphaned toggle
  • 10 module pills wrap to 2 rows; toggle label orphans onto row 2
  • Procurement vs Production, Inventory vs Finance vs Service are near-duplicates at 7px dot
  • Zero-count pills (Project, HR, Service = 0) at full opacity, equal weight
  • Glassmorphism so subtle the toolbar barely separates from the canvas
  • Pills 22px tall on mobile; zoom buttons 32×32
After solid bar, one control
[Module ▾: All]  ·  [☐ Show system FKs]  ·  [Hide graph]
status pill (bottom-right): Showing 40 of 50 tables
  • Module filter becomes one select — searchable, touch-friendly, kills the wrap
  • Solid toolbar pinned to canvas top (glass stays dark-mode-only)
  • Module colors remain on graph nodes (the data) and filter dots
  • Zero-count modules appear in the select but dimmed
  • Same features (expand, pop card, URL state) — only chrome changes
4 · Light mode — dark-first orphan vs first-class theme
Before faint 2.74:1, glass invisible
  • Dot grid invisible; glass buttons/toolbar lose effect → flat
  • Sidebar text, breadcrumb, pagination, section arrows low-contrast gray
  • --clr-text-faint #9198a1 = 2.74:1 — fails AA
  • Method category pills nearly indistinguishable on white
After faint 4.9:1, solid surfaces
  • --clr-text-faint → #656d76 = 4.9:1 (was 2.74:1)
  • No glass in light mode — solid `surface` for toolbar/buttons/pop cards
  • Sidebar on white nav bg with real muted text (#57606a, 7.2:1)
  • Accent `#0969da` (4.9:1) + strong `#0550ae` (8.4:1)
  • Semantic colors re-tuned for white: success/warning/danger all ≥ 4.8:1
5 · Mobile — overflow vs stacked cards
Before 480px overflow at 390px viewport
  • Horizontal overflow: scrollWidth 480 vs 390 — field table pushes the page wider
  • Hamburger 30×26, TOC pills 23px, trace buttons 30px, section toggles 18px
  • Sticky TOC scrolls with no scroll affordance; Graph pill can sit off-screen
  • Graph labels unreadable; zoom controls tiny
After cards, 44px targets
ItemId
String · PK
item number used as FK in every transaction table
Product
Int64 → EcoResProduct.RecId
FK to the shared global product definition
  • Tables → stacked cards under 700px (name / type / FK / note) — kills overflow
  • Every target ≥ 44px: hamburger, TOC pills, trace, pager, section toggles
  • TOC pills scroll with an edge fade affordance
  • Graph gets a full-screen tap-to-expand on mobile
6 · Accessibility pass (computed, WCAG 2.1 AA)
Before 2 fails
  • --clr-text-faint dark 2.28:1 FAIL — placeholders, meta, FK labels
  • --clr-text-faint light 2.74:1 FAIL
  • curated badge #ab47bc on dark 3.93:1 FAIL
  • 30+ controls under 40px (desktop) / 44px (mobile)
  • Light-mode interactive elements wash out (glass, faint borders)
After all pass
  • faint dark #6e7681 = 4.45:1 PASS
  • faint light #656d76 = 4.9:1 PASS
  • Curated rows use success green #3fb950 = 7.5:1 instead of purple
  • Primary button: near-black ink on accent = 5.1:1 PASS
  • All hit targets ≥ 44px touch / 32px dense desktop
