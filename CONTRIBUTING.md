# Contributing

Thanks for your interest in contributing to FnO Navigator.

Guidelines
- Report issues by opening an Issue with steps to reproduce and expected behaviour.
- For code changes, fork the repository and open a Pull Request against `main`.
- Keep changes small and focused. Include tests or a runnable repro where appropriate.

Branch & Commit Style
- Branches: `feature/` or `fix/` prefixes (e.g. `feature/table-path-finder`).
- Commits: use Conventional Commits (e.g. `feat:`, `fix:`, `docs:`, `chore:`).

Testing & CI
- Run `npm install` and `npm run build` locally to ensure the project builds before opening a PR.

License
- By contributing, you agree to license your contributions under the project's MIT license.

Thank you — maintainers will review PRs as time permits.
